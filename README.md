# Drum Sequencer

A browser-based step sequencer and rhythm educator 
built with the Web Audio API.

Built in vanilla HTML5. No dependencies. Works in any browser.

## What It Does
- Step-based beat programming across multiple tracks
- BPM control with stable Web Audio clock scheduling
- Visual metronome — see the rhythm as you hear it
- Demonstrates subdivision, pattern, and musical mathematics

## Why
Rhythm is mathematics. A sequencer that makes that 
relationship visible teaches both simultaneously. 
Inspired by the Arturia step sequencer approach — 
a great drum machine is also a great metronome.
